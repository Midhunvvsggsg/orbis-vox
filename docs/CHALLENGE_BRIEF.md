# Challenge brief: Earth Jukebox (NASA Space Apps 2026)

Condensed from the official challenge text.

## The gap
NASA's Earth Information Center (EIC) produces striking visualizations of a changing planet (temperature, ocean currents, aerosols, CO2, night lights, forests). They are almost entirely visual, which excludes blind and low-vision users and limits how anyone can explore the science.

## The ask
Build an "Earth Jukebox": an interface, script or application that pairs EIC visual frames with dynamic sonifications generated in real time (or a curated set of original generated audio files with an explanation of the process).

A person should be able to select or experience a specific EIC visualization alongside its soundscape.

## Suggested methods (we choose our own)
- Computer vision on color, brightness, shapes, pixel density.
- Map those to pitch, tempo, rhythm, volume, instrumentation.
- Apply musical scales and harmonies so the result is pleasant, not noise.
- Artistic rulesets driving synth parameters.

## Themes the brief stresses
- **Accessibility is core:** screen-reader compatibility, rich descriptive text with the audio, tactile or alternative feedback.
- **Data vs music:** balance faithful translation with musical, listenable output.
- **Exploration:** the sight-to-sound translation should be exploratory, blending science and artistic expression.
- **Storytelling:** document the "why" behind choices; convey beauty and urgency of change.

## Accepted deliverable forms
Interactive web jukebox, desktop app, backend API endpoint, or a playlist of generated audio files with an explanation. ORBIS VOX does the web jukebox AND offers WAV downloads, so it covers both the interactive and the playlist forms.
